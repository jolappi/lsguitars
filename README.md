# Lapland Shaman Guitars

Portfolio site for Lapland Shaman Guitars — one-of-a-kind electric guitars handmade in Nokia, Finland.

**Live site:** https://jounilappi.hopto.org/lsguitars/

A static site (HTML, CSS and a little JavaScript, no build step):

- `index.html` — the whole page
- `css/` — styles and self-hosted fonts (`fonts/`)
- `js/site.js` — gallery cards, sticky close button and the photo lightbox
- `gallery/` — photos (WebP), `video/` — "In action" clips (MP4) with poster images

Guitar design tool by the same maker: [CNCguitarwizard](https://jounilappi.hopto.org/CNCguitarwizard/).
